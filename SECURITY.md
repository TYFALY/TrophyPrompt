# Security Policy

TrophyPrompt is a local tool running on your own machine to parse and edit offline PS3 trophy files. We don't host servers, collect analytics, or store user data.

## Supported Versions

Always use the latest release. Newer versions fix bugs, update native binary dependencies (`pfdtool`), and improve cross-platform stability.

| Version | Supported | Notes |
| :--- | :--- | :--- |
| Latest Release | Yes | Active fixes and updates |
| Older Versions | No | Please update to the latest build before reporting issues |

## Reporting Bugs or Vulnerabilities

If you find a security bug, crash exploit, or issue with file handling:

1. Open a **Private Security Advisory** via the **Security** tab on GitHub (or email the maintainers).
2. Give a brief explanation and steps to reproduce.
3. Give us a little time to look into it before posting it publicly.

For regular non-security bugs, just open a standard issue!
